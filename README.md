# ☕ Reto: La Cafetería Asíncrona

Simulación de un flujo de pedidos utilizando **Async/Await** y **Promesas** en JavaScript.

## Requisitos
- [Node.js](https://nodejs.org/) instalado.

## Instalación y Ejecución
1. Clona este repositorio o descarga el archivo `reto2_cafeteria.js` que esta dentro de este repositorio.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta el comando:
   ```bash
   node index.js
   ```
> [!NOTE]
> Si se desea hacer pruebas con diferentes pedidos, modificar el valor del parámetro de `procesarPedido()` que se encuentra al final del código de `index.js`.
> Ejemplo: `procesarPedido("cappuccino")`;
